安装ollama

本教程测试机器是windows10 64位 amd架构 + 1080ti + NVIDIA STUDIO 581驱动版本
最近搞了一台1080ti显卡的机器，准备从0学习大模型的各种内容，如skill/rag等，这里用来记录遇到的一些问题。

环境配置

确定安装环境

在安装之前，应该确认一下自己的显卡驱动的版本和ollama是否适配。比如我这个电脑比较老旧，1080ti的显卡，在使用0.33版本的ollama的时候，要求显卡驱动要达到570的版本，否则无法使用。

安装ollama

ollama的官网下载地址是: ollama的github下载地址。

下载之后就双击安装就行。

拉取大模型

安装完成之后，关闭命令行重新打开，这样可以重新载入环境变量，然后执行下面的命令，确认能找到ollama: 


ollama --version
如果提醒找不到ollama，那么你应该检查你的环境变量中是否能看到ollama，一般来讲ollama自动就会添加到环境变量中。 


    ollama version is 0.33.3

能看到输出之后，就可以开始拉取大模型了，毕竟我这个电脑上1080ti 11GB的版本，所以我使用qwen2.5 3b的版本。大家可以根据自己的显卡显存和自己的用途（学习用/工程用）自行抉择。

国内用户需要换国内源，需要进入系统设置的高级环境变量，新建一个变量：

在python中使用

在使用之前，需要先执行命令运行ollama: 


ollama serve
如果你安装完ollama之后没有什么特殊设置，理论上他已经运行了

打开浏览器访问ollama的默认端口(11434): 本地的ollama，如果你能看到"Ollama is running"，证明ollama serve正在运行。

在ollama正常运行的情况下，可以运行代码（使用openai包的方式），下面先展示代码，而具体环境包版本将列在最后。 

# -*- coding: utf-8 -*-
from openai import OpenAI
"""
before use this python script, your should have run "ollama serve" in your cmd.
"""
def main():
    client = OpenAI(
        base_url="http://localhost:11434/v1",
        api_key="ollama"
    )
    """
>>> ollama list
NAME          ID              SIZE      MODIFIED
qwen2.5:3b    357c53fb659c    1.9 GB    4 hours ago
qwen3.5:2b    0689d44085e0    2.7 GB    28 hours ago
    """
    response = client.chat.completions.create(
        model="qwen2.5:3b",  # the model name should be your model name in "ollama list"
        messages=[
            {
                "role": "user",
                "content": "Do you think using NVIDIA1080Ti to study basic LLMs usage is a good idea?"
            }
        ]
    )
    print(response.choices[0].message.content)
if __name__ == "__main__":
    main()
注意："role": "user"常见的值只有三个：system, user和assistant。有可能有的有tool或者developer，根据实际情况填写。
注意：model="qwen2.5:3b"必须是你自己的模型。第一次运行，由于需要加载模型，所以比较慢，短时间内多次运行，就快了。
